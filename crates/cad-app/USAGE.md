# cad-app 使い方ガイド

gfp-cad の GUI エディタ（**軽量BIM**）。平面図を見て・触って・編集し、DXF などへ出力します。
Windows / macOS 対応（winit + wgpu 自前描画、書体は Gen Interface JP）。

起動:

```sh
cargo run -p cad-app                 # 組込サンプルで起動
cargo run -p cad-app -- plan.json    # 既存の Building JSON を開いて起動
```

---

## 画面の見かた

- **キャンバス**: 平面図。通り芯（グリッド）、壁、開口、部屋の塗り、部屋名＋面積を表示。
- **上部の HUD**（ステータス行）: 現在のツール、未保存マーク `*`、undo/redo の可否、主要キー。
- **左上のインスペクタ**: 選択中エンティティの詳細（読み取り専用）。

座標系はミリメートル（mm）。角度は度。原点は左下、y は上向き。

---

## ツール（数字キーで切替）

| キー | ツール | 操作 |
|----|------|------|
| `0` | **選択** | クリックで選択。**ノードをドラッグで移動**（後述）。 |
| `1` | **壁** | クリックで始点 → クリックで終点。続けて描くと連鎖（前の終点が次の始点）。 |
| `2` | **部屋** | 壁で囲まれた領域の内側を **1クリック**（シード点を置く）。 |
| `3` | **開口** | 壁の近くをクリック → その壁にドアを配置（約 0.5m 以内）。 |

作図中はカーソルが**グリッド交点・軸・既存ノード**へ吸着します。

---

## マウス操作

| 操作 | 効果 |
|----|----|
| 空き領域をドラッグ | パン（画面移動） |
| ホイール | ズーム（カーソル位置を固定して拡大縮小） |
| クリック（選択モード） | 壁 / 開口 / 部屋 / ノードを選択 |
| **ノードのハンドルをドラッグ**（選択モード） | ノードを移動 → 壁・部屋が追従 |

---

## ノード移動編集（このエディタの肝）

壁の端点は**共有ノード**で表現されています。端点が一致する壁は同じノードを指すので、
**構造的に接合していて離れません**。部屋は独立ポリゴンではなく、壁グラフの**閉領域（面）**
として導出されます。

そのため:

1. **選択モード**（`0`）にすると、各ノードに小さな**ハンドル**（四角）が表示されます。
2. ハンドルをドラッグすると、そのノードを端点に持つ**壁がすべて追従**し、
   囲まれた**部屋の境界・面積も自動で再計算**されます。
3. ドラッグ中はグリッドに吸着します。離すと確定（**1回の undo ステップ**）。

> 壁と部屋が「別々のデータ」ではなく「壁グラフとそこから導かれる面」なので、
> 動かしてもズレません。これが軽量BIMとしての設計上の要点です。

---

## 部屋・面積について

- 部屋は**シード点**（部屋内部の1点）で定義します。境界・面積・周長は壁の閉領域から**自動導出**。
- 壁を動かす／消すと、部屋もそれに追従します（囲まれなくなると面積は表示されません）。
- インスペクタと図面ラベルに面積（㎡）を表示します。
- 入れ子（部屋の中の部屋）や浮いた内側ループ（穴）も面積計算に反映されます。

## ファイル / 編集

| キー | 操作 |
|----|----|
| `Ctrl+S` | 保存（未設定ならダイアログ）。形式は Building JSON。 |
| `O` | JSON を開く |
| `L` | 組込サンプルを読み込む |
| `F` | 全体を画面にフィット |
| `H` / `?` | 使い方ガイドの開閉 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Enter` | 確定 |
| `Esc` | 取消・選択解除（ガイド表示中はガイドを閉じる） |

保存形式（Building JSON）は cad-mcp（LLM）・cad-db（クラウド）と同一なので、
AI が組んだモデルを無変換で開けます。

---

## インスペクタの表示内容

選択したものに応じて左上に表示されます:

- **壁**: 長さ・厚み・材料・内壁/外壁
- **開口**: 種類・幅・高さ・窓台高さ
- **部屋**: 名前・面積（㎡）・周長（mm）
- **ノード**: 座標・接続壁の本数（「ドラッグで移動」）

---

## よくある操作の流れ

**四角い部屋をつくる**
1. `1`（壁）で四隅を順にクリックして閉じる（角は同じ点をクリックすると接合）。
2. `2`（部屋）でその内側を1クリック → 面積が表示される。

**間取りを微調整する**
1. `0`（選択）にする。
2. 角のノードをドラッグ → 壁が追従し、面積がリアルタイムに変わる。

**ドアを付ける**
1. `3`（開口）で対象の壁の近くをクリック。

---

## 既知の制約（現時点）

- 開口は現状ドアのみ（窓・種類変更は今後）。
- ノードを別ノードとぴったり同じ座標へ重ねると、面が閉じない場合があります
  （接合したい場合は壁を引き直す）。将来はドロップ時の自動マージを予定。
- インスペクタは読み取り専用（名前・数値の直接編集は今後）。

---

## トラブルシューティング

- **部屋をクリックしても作れない**: 壁で完全に囲まれていません（HUD に「囲まれた領域内を
  クリックしてください」と出ます）。壁の端点がきちんと接合しているか確認を。
- **面積が出ない/消えた**: 壁を動かして部屋が囲まれなくなった可能性。囲みを閉じ直してください。
